# 微信直连 2.4.2

适配 Windows x64 微信 4.2.0.13。需要 Codex 桌面应用、Node.js >= 22、Python 3.12 x64。解压完整安装包后运行 install.cmd；首次安装先正常登录微信，已有绑定可离线更新。

提供 13 个 MCP 工具，读取联系人和聊天，按用户授权发送文字、内置表情和当前账号添加的单个表情。安装不会发送测试消息，也不会开启后台自动回复。

当前客户端的聊天读取及文字/图片对象准备已验证；真实文字、图片或动图发送尚未完成验收。准备成功不等于发送成功。未知发送结果只查询原操作编号。

运行时可用 WECHAT_DIRECT_PYTHON、WECHAT_DIRECT_NODE 指定。私人状态位于 %LOCALAPPDATA%\CodexWeChatDirect，请勿上传该目录。微信更新后需要重新适配。

源码与完整文档：https://github.com/huaxueyu1105/wechat-direct
