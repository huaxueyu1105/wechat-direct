# 微信直连 2.5.0-dev.3

适配 Windows x64 微信 4.2.0.13。需要 Node.js 22+、Python 3.12 x64。Codex 用户解压完整安装包后运行 `install.cmd`。Kimi Code、Gemini CLI、Claude Desktop、Claude Code 和 DeepSeek 用户请按 [其他 AI 客户端](<其他 AI 客户端.md>) 中的步骤生成本地 MCP 配置。首次绑定先正常登录微信，已有绑定可继续使用。

提供 25 个 MCP 工具，读取联系人和聊天，按用户授权发送文字、表情、普通图片和文件，并管理一次性、每日、每周定时任务、账号绑定、发送恢复、执行器及缓存。普通图片限静态 PNG/JPEG、20 MiB、四千万像素，文件限 100 MiB。安装不会发送测试消息，也不会启动定时执行器或后台自动回复。

前一开发版 dev.1 已在文件传输助手中实测文字、静态 PNG、TXT 文件及一次性定时文字，均匹配到新的服务器记录。本版维护修复仅离线验证；尚未覆盖其他联系人/群聊、JPEG、大文件、表情和循环任务的实机发送。准备成功不等于发送成功，未知发送结果只查询原操作编号；人工核对后才能关闭未知记录，关闭不证明成功或失败。

定时任务默认上海时区，创建时沿用稳定 taskId。保存任务后需运行插件内 `scripts/scheduler.mjs --interval 15`；可用 `--once` 配合已有 Windows 任务计划。电脑需可运行且微信已登录，执行器不会自动注册系统任务。漏跑只处理最近到期一次；未知状态阻止后续发送。源文件改变或删除会阻止定时附件发送。完整参数见源码 README。

执行器支持 `--status`、`--stop`；停止会等待当前调用结束。多账号通过 `scripts/wechat.mjs bind --account '<微信号>'` 显式选择。可再生缓存默认 1024 MiB、7 天，可查询、调整及清理；正在使用的分片和结果未知的附件可能超过配额，原数据库、绑定和任务不会被清理。

运行时可用 WECHAT_DIRECT_PYTHON、WECHAT_DIRECT_NODE 指定。私人状态位于 %LOCALAPPDATA%\CodexWeChatDirect，请勿上传该目录。微信更新后需要重新适配。

源码与完整文档：https://github.com/huaxueyu1105/wechat-direct
