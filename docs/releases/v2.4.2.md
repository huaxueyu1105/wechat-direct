# 微信直连 v2.4.2：首次公开源码

Windows x64 / 微信 4.2.0.13 / Python 3.12 x64 / Node.js >= 22。

本次以 MIT 许可证公开插件、原生驱动、测试及构建工具。第三方只读数据库模块保留 Apache-2.0 许可证和修改说明。

- 提供 13 个 MCP 工具，读取联系人和聊天，按授权发送文字、内置表情及账号添加的单个表情。
- 发送操作持久化去重，未知结果只查询；表情来源、账号绑定及客户端摘要严格核对。
- 14 项 Node 测试、51 项 Python 测试通过；驱动编译、安装包完整性和发布内容隐私检查通过。
- 安装包不包含账号、聊天、密钥、私人表情或实机日志。安装和构建不发送测试消息。

这是实验性发布。当前客户端的聊天读取、文字及图片对象准备已在开发机通过，真实文字、图片和动图发送尚未完成验收。准备检查成功不代表消息发送成功。

下载 `wechat-direct-2.4.2-windows-x64.zip`，解压后运行 `install.cmd`；首次安装前请正常登录已适配版本的微信。已有绑定可离线更新。校验值见 `SHA256SUMS.txt`。
